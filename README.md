# Қазақ тілі — учим казахский

Сайт для изучения казахского языка: словарь и 28 уроков в 10 разделах.

## Запуск

Откройте PowerShell в этой папке и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```

Затем откройте http://localhost:8080. Сайт работает и без сервера: достаточно открыть `index.html`.
